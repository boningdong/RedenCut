# Approved UI reference

Open `podcut-ui-final.html` directly in a browser; it is self-contained and does not need a development server.

The approved direction is single-column dialogue with overlap markers and a local Read / Align switch inside each overlap card.

See `podcut-ui-requirements.md` for the English design requirements.

Earlier HTML alternatives and screenshots are retained for comparison, not as additional production requirements.

These files were originally saved outside the Git repository in the enclosing workspace under `docs/ui-mock/2026-09-10/`; this directory brings the original artifacts into the implementation checkout.
